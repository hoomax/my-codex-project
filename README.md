# CryptoManager

A minimal Farsi application for managing cryptocurrency transactions. The application is built using Python's Tkinter library and provides the following features:

- Right-to-left menus and Persian labels.
- Register new transactions with details such as currency type, date, amount, unit price, fees and transaction type.
- View a list of all transactions and the total amount per currency.

## Requirements

- Python 3.10+
- Tkinter (usually included with Python on Windows)

To run the application:

```bash
python crypto_manager.py
```

On systems without a graphical environment this command will fail.
